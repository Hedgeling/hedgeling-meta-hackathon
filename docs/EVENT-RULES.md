# Working rules record

Recorded October 27, 2026 from organizer clarifications supplied by the project owner. This is a paraphrased implementation checklist, not a substitute for the Official Rules or an independent organizer approval of this project. The participant details page required access unavailable to the reader used during preparation.

Source: [Meta Global AI Developer Hackathon participant details](https://cerebralvalley.ai/e/meta-ai-developer-hackathon/details). The owner supplied the relevant answers directly in the development conversation.

- Submit a fresh public repository containing only event work; do not import the prior codebase or its Git history. Pre-kickoff scaffolding must not be copied into it. Declared open-source dependencies and pre-existing public datasets are allowed.
- An existing private product may remain a hosted service, provided the README identifies the code written during the event. The current clarification resolves the earlier uncertainty about proprietary hosted dependencies.
- The three-minute video must open with a clear distinction between the pre-existing product and this week's contributions. Demonstrate the new features rather than presenting a slide deck or claiming the whole old product as new.
- Meta models must be a real part of execution. Other providers and coding assistants are permitted; coding-assistant disclosure is not required.
- The owner confirmed October 26, 2026 as the applicable start date. Submit by November 4, 2026 at 9 PM Eastern through the event platform, with the public repo, three-minute video, and all accepted teammates. Maximum team size is four under the supplied guide.
- Supplied judging weights: Impact 30%, Meta AI Tooling 25%, Technical Depth and Execution 20%, Demo 25%.
- The supplied clarification does not specify a mandatory source license. The owner chose Apache-2.0 for this public extract; the private product retains its own terms.

There is no claim that public code alone recreates the proprietary service. Document its required access/configuration and arrange judge access so the demonstrated workflow can be verified. Fixtures remain clearly labeled and do not substitute for a real Meta-powered final demonstration.
